dibusynth — cómo funciona

Dibujás, y el dibujo suena. La altura en el canvas = la nota. Arriba es agudo, abajo es grave. El color elige el instrumento. Los barridos recorren el dibujo y tocan lo que encuentran.

Para empezar

  1. Elegí un color en la fila de instrumentos.
  2. Dibujá algo — una línea horizontal suena mientras el barrido la cruza.
  3. Tocá ▶ — si no hay barrido activo, se activa → automáticamente.
  4. Mové las líneas arriba o abajo para cambiar la nota.

Herramientas

✏
Lápiz — trazos libres. El grosor se ajusta en ⚙.
—
Línea recta — continua o punteada, elegís en ⚙.
+
Crear figura — círculo, cuadrado, triángulo, estrella o texto. Elegís en ⚙.
⚙
Opciones — muestra los ajustes de la herramienta activa.
✥
Mover — tocá un trazo y arrastralo a otra posición.
⌁
Recolorear — tocá un trazo para cambiarle el color y el instrumento.
⬜
Borrador — elimina el trazo que toques.
↩
Deshacer — revierte hasta 100 pasos.
✕
Borrar todo — limpia el canvas completo.
